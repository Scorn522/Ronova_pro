## 主要合同变化

1. 主路径从“破坏后修复可用”明确提升为“第一次非法效果不能发生”。修复仍需有效，但它是事故结果。
2. 防护当前会话激活不等持久 ACK、不等 END tick；跨线程读取同一准确策略，撤销/换身/载体发布与实际变更有定序。
3. 攻击先封当前已知源/回填/执行/发布，再执行准确本体、记录和来源 HARD 处置；不等目标先产生新身体、取得 executed CLEAR 才拒绝准入。
4. 原字段/实际 writer/集合视图/整载体发布、0ms task、handler/draw、文件截断和提交都写明真实截点；通知和事后回滚不能改名成 veto。
5. 已知受保护对象的准确有害变更立即拒绝，不需先完成攻击者/producer 全图；未知跨对象关系仍不乱删。
6. `ENTRY_REJECTED / WRITE_REJECTED / EVALUATED_NO_EFFECT / REPAIRED_AFTER_BREACH / UNPROVEN` 分开；复用当前记录，不再加一棵 Evidence 架构。
7. 增加 33 个机制子用例，归入原 39 个父项，均 NOT_RUN；原有修复场景保留原义。独立观察 attempted>0、非法实际效果和正常邻居，停修复后仍能过前置正例。
8. 明确玩家零手填与进程内部必要参数不同；必须证明真正早期 bootstrap，不能给 premain-only 的现有 agentmain 编造能力。
